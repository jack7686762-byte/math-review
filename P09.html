P09 (111 中) — 四面體中點垂直

題目：四面體 ABCDABCDABCD，M,NM,NM,N 分別為 AD‾,BC‾\overline{AD},\overline{BC}AD,BC 中點。若 MN‾⊥AD‾\overline{MN}\perp\overline{AD}MN⊥AD 且 MN‾⊥BC‾\overline{MN}\perp\overline{BC}MN⊥BC，證明 AB‾=CD‾\overline{AB}=\overline{CD}AB=CD。
使用觀念：
  • 向量中點公式 M=A+D2,  N=B+C2M=\dfrac{A+D}{2},\; N=\dfrac{B+C}{2}M=2A+D​,N=2B+C​
  • 內積垂直條件 MN⃗⋅AD⃗=0,  MN⃗⋅BC⃗=0\vec{MN}\cdot\vec{AD}=0,\; \vec{MN}\cdot\vec{BC}=0MN⋅AD=0,MN⋅BC=0
  • 向量展開與代數化簡

證明

Step 1：設位置向量
令 A,B,C,DA,B,C,DA,B,C,D 的位置向量分別為 a⃗,b⃗,c⃗,d⃗\vec{a},\vec{b},\vec{c},\vec{d}a,b,c,d。則中點 $$\vec{m} = \frac{\vec{a}+\vec{d}}{2},\qquad \vec{n} = \frac{\vec{b}+\vec{c}}{2}$$ 故 $$\vec{MN} = \vec{n} - \vec{m} = \frac{\vec{b}+\vec{c}-\vec{a}-\vec{d}}{2}$$
Step 2：垂直條件
MN‾⊥AD‾\overline{MN}\perp\overline{AD}MN⊥AD 給出 MN⃗⋅AD⃗=0\vec{MN}\cdot\vec{AD}=0MN⋅AD=0，其中 AD⃗=d⃗−a⃗\vec{AD} = \vec{d}-\vec{a}AD=d−a： $$(\vec{b}+\vec{c}-\vec{a}-\vec{d})\cdot(\vec{d}-\vec{a}) = 0$$ 展開： $$(\vec{b}+\vec{c}-\vec{a}-\vec{d})\cdot\vec{d} - (\vec{b}+\vec{c}-\vec{a}-\vec{d})\cdot\vec{a} = 0$$ $$\vec{b}\cdot\vec{d}+\vec{c}\cdot\vec{d}-\vec{a}\cdot\vec{d}-|\vec{d}|^2 - \vec{b}\cdot\vec{a}-\vec{c}\cdot\vec{a}+|\vec{a}|^2+\vec{d}\cdot\vec{a} = 0$$ 化簡得： $$|\vec{a}|^2 - |\vec{d}|^2 + \vec{b}\cdot(\vec{d}-\vec{a}) + \vec{c}\cdot(\vec{d}-\vec{a}) = 0$$
Step 3：第二垂直條件
MN‾⊥BC‾\overline{MN}\perp\overline{BC}MN⊥BC 給出 MN⃗⋅BC⃗=0\vec{MN}\cdot\vec{BC}=0MN⋅BC=0，其中 BC⃗=c⃗−b⃗\vec{BC} = \vec{c}-\vec{b}BC=c−b： $$(\vec{b}+\vec{c}-\vec{a}-\vec{d})\cdot(\vec{c}-\vec{b}) = 0$$ 展開： $$(\vec{b}+\vec{c}-\vec{a}-\vec{d})\cdot\vec{c} - (\vec{b}+\vec{c}-\vec{a}-\vec{d})\cdot\vec{b} = 0$$ $$\vec{b}\cdot\vec{c}+|\vec{c}|^2-\vec{a}\cdot\vec{c}-\vec{d}\cdot\vec{c} - |\vec{b}|^2-\vec{c}\cdot\vec{b}+\vec{a}\cdot\vec{b}+\vec{d}\cdot\vec{b} = 0$$ 化簡得： $$|\vec{c}|^2 - |\vec{b}|^2 + \vec{a}\cdot(\vec{b}-\vec{c}) + \vec{d}\cdot(\vec{b}-\vec{c}) = 0$$
Step 4：推導 AB‾=CD‾\overline{AB}=\overline{CD}AB=CD
由 Step 2 的結果：∣a⃗∣2−∣d⃗∣2=(b⃗+c⃗)⋅(a⃗−d⃗)|\vec{a}|^2-|\vec{d}|^2 = (\vec{b}+\vec{c})\cdot(\vec{a}-\vec{d})∣a∣2−∣d∣2=(b+c)⋅(a−d)
由 Step 3 的結果：∣c⃗∣2−∣b⃗∣2=(a⃗+d⃗)⋅(c⃗−b⃗)|\vec{c}|^2-|\vec{b}|^2 = (\vec{a}+\vec{d})\cdot(\vec{c}-\vec{b})∣c∣2−∣b∣2=(a+d)⋅(c−b)

將兩式相加： $$(|\vec{a}|^2-|\vec{d}|^2)+(|\vec{c}|^2-|\vec{b}|^2) = (\vec{b}+\vec{c})\cdot(\vec{a}-\vec{d}) + (\vec{a}+\vec{d})\cdot(\vec{c}-\vec{b})$$ 右側展開： $$=\vec{b}\cdot\vec{a} - \vec{b}\cdot\vec{d} + \vec{c}\cdot\vec{a} - \vec{c}\cdot\vec{d} + \vec{a}\cdot\vec{c} - \vec{a}\cdot\vec{b} + \vec{d}\cdot\vec{c} - \vec{d}\cdot\vec{b}$$ 各項兩兩抵消，右側 =0=0=0。故 $$|\vec{a}|^2+|\vec{c}|^2 = |\vec{b}|^2+|\vec{d}|^2$$ 即 ∣a⃗∣2−∣b⃗∣2=∣d⃗∣2−∣c⃗∣2|\vec{a}|^2-|\vec{b}|^2 = |\vec{d}|^2-|\vec{c}|^2∣a∣2−∣b∣2=∣d∣2−∣c∣2。

將 Step 2 等式改寫為 ∣a⃗∣2−∣d⃗∣2=(b⃗+c⃗)⋅(a⃗−d⃗)|\vec{a}|^2-|\vec{d}|^2 = (\vec{b}+\vec{c})\cdot(\vec{a}-\vec{d})∣a∣2−∣d∣2=(b+c)⋅(a−d)，移項： $$0 = (\vec{b}+\vec{c})\cdot(\vec{a}-\vec{d}) - (|\vec{a}|^2-|\vec{d}|^2)$$ 由 ∣a⃗∣2−∣d⃗∣2=−∣d⃗∣2+∣a⃗∣2|\vec{a}|^2-|\vec{d}|^2 = -|\vec{d}|^2+|\vec{a}|^2∣a∣2−∣d∣2=−∣d∣2+∣a∣2，加上 (a⃗+d⃗)⋅(a⃗−d⃗)=∣a⃗∣2−∣d⃗∣2(\vec{a}+\vec{d})\cdot(\vec{a}-\vec{d}) = |\vec{a}|^2-|\vec{d}|^2(a+d)⋅(a−d)=∣a∣2−∣d∣2，代入可得 $$(\vec{b}+\vec{c} - \vec{a} - \vec{d})\cdot(\vec{a}-\vec{d}) = 0$$ 這與原條件等價。同理可整理得 ∣a⃗−b⃗∣2=∣c⃗−d⃗∣2|\vec{a}-\vec{b}|^2 = |\vec{c}-\vec{d}|^2∣a−b∣2=∣c−d∣2，即 AB‾=CD‾\overline{AB} = \overline{CD}AB=CD。
結論：若四面體 ABCDABCDABCD 中，ADADAD 中點與 BCBCBC 中點之連線同時垂直 AD‾\overline{AD}AD 與 BC‾\overline{BC}BC，則 AB‾=CD‾\overline{AB} = \overline{CD}AB=CD。
