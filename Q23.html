題目 23（109，易）

空間中三個向量 a⃗,b⃗,c⃗\vec a,\vec b,\vec ca,b,c，已知 a⃗=(3,1,5)\vec a=(3,1,5)a=(3,1,5)，且 2a⃗×b⃗+3b⃗×c⃗−7c⃗×a⃗=(12,−4,11)2\vec a\times\vec b+3\vec b\times\vec c-7\vec c\times\vec a=(12,-4,11)2a×b+3b×c−7c×a=(12,−4,11)，試求 a⃗,b⃗,c⃗\vec a,\vec b,\vec ca,b,c 三個向量所張平行六面體體積。

  • 外積性質：a⃗×b⃗=−(b⃗×a⃗)\vec a\times\vec b = -(\vec b\times\vec a)a×b=−(b×a)，(a⃗×b⃗)⋅c⃗=(\vec a\times\vec b)\cdot\vec c =(a×b)⋅c= 行列式值 === 平行六面體體積。
  • 平行六面體體積：V=∣[a⃗,b⃗,c⃗]∣=∣(a⃗×b⃗)⋅c⃗∣=∣det⁡(a⃗,b⃗,c⃗)∣V = |[\vec a,\vec b,\vec c]| = |(\vec a\times\vec b)\cdot\vec c| = |\det(\vec a,\vec b,\vec c)|V=∣[a,b,c]∣=∣(a×b)⋅c∣=∣det(a,b,c)∣。
  • 線性組合：利用外積的反交換性及純量乘法，將給定等式整理成某個外積的組合。
步驟 1：利用反交換性將各項統一到 b⃗×c⃗\vec b\times\vec cb×c 和 c⃗×a⃗\vec c\times\vec ac×a 形式
已知 2a⃗×b⃗+3b⃗×c⃗−7c⃗×a⃗=(12,−4,11)2\vec a\times\vec b + 3\vec b\times\vec c - 7\vec c\times\vec a = (12,-4,11)2a×b+3b×c−7c×a=(12,−4,11)。

利用 a⃗×b⃗=−(b⃗×a⃗)\vec a\times\vec b = -(\vec b\times\vec a)a×b=−(b×a)，但保持 b⃗×c⃗\vec b\times\vec cb×c 不變。這裡我們需要將所有項寫成 b⃗×c⃗\vec b\times\vec cb×c 和 c⃗×a⃗\vec c\times\vec ac×a 的組合。
步驟 2：與 a⃗\vec aa 作內積
將給定等式與 a⃗\vec aa 作內積：
a⃗⋅(2a⃗×b⃗+3b⃗×c⃗−7c⃗×a⃗)=a⃗⋅(12,−4,11)\vec a\cdot(2\vec a\times\vec b + 3\vec b\times\vec c - 7\vec c\times\vec a) = \vec a\cdot(12,-4,11)a⋅(2a×b+3b×c−7c×a)=a⋅(12,−4,11)。

因為 a⃗⋅(a⃗×b⃗)=0\vec a\cdot(\vec a\times\vec b)=0a⋅(a×b)=0（a⃗×b⃗⊥a⃗\vec a\times\vec b\perp\vec aa×b⊥a），
且 a⃗⋅(c⃗×a⃗)=0\vec a\cdot(\vec c\times\vec a)=0a⋅(c×a)=0，
故左邊 =3 a⃗⋅(b⃗×c⃗)=3[a⃗,b⃗,c⃗]= 3\,\vec a\cdot(\vec b\times\vec c) = 3[\vec a,\vec b,\vec c]=3a⋅(b×c)=3[a,b,c]。

右邊 =(3,1,5)⋅(12,−4,11)=36−4+55=87= (3,1,5)\cdot(12,-4,11) = 36-4+55 = 87=(3,1,5)⋅(12,−4,11)=36−4+55=87。

所以 3[a⃗,b⃗,c⃗]=87 ⇒ [a⃗,b⃗,c⃗]=293[\vec a,\vec b,\vec c] = 87 \ \Rightarrow\ [\vec a,\vec b,\vec c] = 293[a,b,c]=87 ⇒ [a,b,c]=29。
平行六面體體積 V=∣[a⃗,b⃗,c⃗]∣=29V = |[\vec a,\vec b,\vec c]| = 29V=∣[a,b,c]∣=29。
步驟 3：驗證
亦可與 b⃗\vec bb 或 c⃗\vec cc 作內積，結果相同：
b⃗⋅(2a⃗×b⃗+3b⃗×c⃗−7c⃗×a⃗)=−7 b⃗⋅(c⃗×a⃗)=−7[a⃗,b⃗,c⃗]=b⃗⋅(12,−4,11)\vec b\cdot(2\vec a\times\vec b + 3\vec b\times\vec c - 7\vec c\times\vec a) = -7\,\vec b\cdot(\vec c\times\vec a) = -7[\vec a,\vec b,\vec c] = \vec b\cdot(12,-4,11)b⋅(2a×b+3b×c−7c×a)=−7b⋅(c×a)=−7[a,b,c]=b⋅(12,−4,11)，
由 b⃗\vec bb 未知無法直接求解，但與 a⃗\vec aa 內積為最簡潔之方法。
答案：29\boxed{29}29​
